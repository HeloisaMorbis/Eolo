ÉOLO — INTEGRAÇÃO COM SUPABASE

Arquivos:
- eolo.html: página do Éolo com a biblioteca Supabase adicionada.
- script.js: integração com autenticação, pacientes, bombinhas, eventos BLE,
  medicamentos, registros diários e ficha de saúde.
- style.css: mantido sem alterações nesta etapa.
- eolo_server.exe: servidor local original.
- image-Photoroom.png: imagem original.
- SUPABASE_POLITICAS.sql: políticas RLS necessárias para o código acessar
  as tabelas com segurança usando usuários autenticados.

COMO USAR:
1. Execute primeiro o banco SQL principal que foi enviado anteriormente.
2. Execute SUPABASE_POLITICAS.sql no SQL Editor do Supabase.
3. No Supabase, em Authentication > Providers, deixe Email habilitado.
4. Para facilitar o primeiro teste, pode desativar temporariamente a confirmação
   de email em Authentication > Settings > Email, se essa opção estiver disponível.
5. Abra o Éolo pelo servidor local (não diretamente pelo arquivo HTML), porque
   o Web Bluetooth precisa de um contexto seguro/localhost.
6. Use Criar uma conta para cadastrar um email e senha.
7. Faça login.
8. Cadastre uma bombinha e teste o BLE.

OBSERVAÇÃO:
A chave sb_publishable é uma chave pública apropriada para uso no frontend.
Nunca coloque uma chave secreta/service_role no código do site.


CADASTRO DE CONTA — NOVO
1. Execute SUPABASE_CRIAR_CONTA.sql no SQL Editor do Supabase.
2. A tela "Criar uma conta" pede email, senha, confirmar senha e idade.
3. A conta é criada pelo Supabase Auth.
4. A idade é enviada para o cadastro e salva em public.usuarios.idade quando o usuário entra no sistema.
5. Para fazer login, use somente email e senha.
6. Se a confirmação de email estiver habilitada no Supabase, confirme o email antes do primeiro login.
